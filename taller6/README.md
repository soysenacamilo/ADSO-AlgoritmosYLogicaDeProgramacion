# Taller 6 — Tablas de Verdad y Operadores Lógicos

Este taller está organizado en carpetas por tema y nivel, siguiendo una estructura similar a los talleres anteriores del repositorio.

## Estructura

```text
taller6/
├── 00_Taller6.md
├── 01_teoria/
│   └── tablas_de_verdad.md
├── 02_ejercicios_basicos/
│   ├── ejercicios 1 al 5
├── 03_ejercicios_intermedios/
│   ├── ejercicios 6 al 10
├── 04_ejercicios_avanzados/
│   ├── ejercicios 11 al 15
└── README.md
```

## Cómo usarlo

- `00_Taller6.md` contiene el documento completo para entregar en formato Markdown.
- `01_teoria/` contiene el resumen teórico.
- Las carpetas de ejercicios contienen cada solución por separado, con tabla de verdad, pseudocódigo y conclusión.
- Completa los datos de la portada antes de entregar.

## Observaciones

- Las tablas usan V para Verdadero y F para Falso.
- Las tablas de cuatro variables tienen 16 filas y la de cinco variables tiene 32 filas.
- En los ejercicios con datos numéricos, las variables A, B, C y D representan el resultado lógico de comparar esos datos.
- En el ejercicio 14, las funciones auxiliares `ExisteMayuscula`, `ExisteNumero` y `ExisteCaracterEspecial` son nombres descriptivos; deben implementarse para ejecutar el algoritmo en un entorno concreto.
