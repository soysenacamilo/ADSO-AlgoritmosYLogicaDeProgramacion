# Diagramas de flujo

La guía del Taller 3 solicita los 15 pseudocódigos completos y recomienda pruebas de escritorio, pero no exige diagramas de flujo. Esta carpeta se conserva para mantener una organización parecida a la del Taller 2. Si el instructor solicita diagramas, se pueden agregar aquí con nombres `ej01.png` hasta `ej15.png` y enlazarlos desde cada ejercicio.
